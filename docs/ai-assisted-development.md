# AI-Assisted Development Notes

## Goal

This project reimplements a simplified local version of a campaign workflow engine based on previous experience.

The goal is to practice AI-assisted backend development and demonstrate:
- RESTful API design
- workflow state transitions
- asynchronous task simulation
- retry and idempotency
- reporting queries
- automated testing
- documentation

## AI Usage Principle

AI tools are used as coding assistants. All generated code will be manually reviewed, tested, and refined before commit.
